# Утилиты

Фронтенд на React + TypeScript + Vite со страницей «Утилиты»:

1. **Покер планирование** — участники, колоды (Фибоначчи, модифицированный Фибоначчи, размеры футболок, степени двойки), скрытое голосование, вскрытие карт, статистика (среднее, медиана, мин/макс, распределение), консенсус и история оценок. Состояние хранится в `localStorage` и синхронизируется между вкладками браузера.
2. **Конвертер Base64** — кодирование/декодирование с поддержкой UTF-8 (кириллица, эмодзи), режим URL-safe, перевод файла в Base64.
3. **JSON валидатор и форматтер** — проверка с указанием строки и столбца ошибки, расстановка переносов строк и отступов (2/4 пробела, табуляция), сортировка ключей, минификация.

Переключение между утилитами — вкладками, адрес вкладки в URL (`#poker`, `#base64`, `#json`).

## Запуск

```bash
npm install
npm run dev      # режим разработки
npm run build    # сборка в dist/
npm run lint
```
